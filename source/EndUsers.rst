End Users
==========

Field Data Collection (FDC) is a map based application that allows you to create, view, and annotate the boundaries for a current or future 811 dig site. The audience for this documentation are locators, excavators, engineers, and emergency response teams that can benefit from a mobile GIS data collection and mapping tool.

.. figure:: /_static/E-Screenshot1.png
   :alt: The Field Data Collection application
   :class: bordered-figure

   *Field Data Collection*   
 
Tools
======

* Active tickets
* Create Geometry
* New GSOC Ticket Request
* Upload File
* Download Features
* Field Strike
* Information Resources


.. caution::
   The FDC application is designed to **supplement** your 811 ticket. Not all utility information has been shared and some features in your ticket boundary may not be shown.
