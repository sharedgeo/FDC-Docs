Getting Started
=================

Field Data Collection (FDC) is a map based application that allows you to create, view, and annotate the boundaries for a current or future 811 dig site. The audience for this documentation are excavators, locators, engineers, and emergency response teams who utilize mobile GIS data collection and mapping to perform critical tasks.

When you open FDC for the first time the landing page displays the default OpenStreetMap basemap and these tools:
* Login
* Layers
* Basemaps
* Zoom to location

.. figure:: /_static/D-LandingPage1.png
   :alt: FDC Landing Page
   :class: with-border

   *FDC Landing Page*

Register and Log In
^^^^^^^^^^^^^^^^^^^^

To get started, click the **Register** link below the sign in form. Enter your information and select **Register**.

.. figure:: /_static/D-Register1.png
   :alt: Register
   :class: with-border

   *Register*

If successful, you will see a message alerting you to verify your email. You must do this before you can sign in. 

.. figure:: /_static/D-Register2.png
   :alt: Verify your email
   :class: with-border

   *Verify your email*

Open your email application and find the email from SharedGeo User Accounts. If you don't see it after a few minutes, check your Spam folder. If you can't find it, go back to the Registration popup and select the option to **Resend Link**. Once you get the email, select **Link to e-mail address verification**. You can now **Log In**.

.. figure:: /_static/D-Login.png
   :alt: FDC Login
   :class: with-border

   *FDC Login*

New Tools
^^^^^^^^^^
You can see that your Toolset has changed with a link to **Log Out** and three new options:

* Search
* Edit features
* Manage documents

.. figure:: /_static/D-LoggedInTools.png
   :alt: Login Enabled Tools
   :class: with-border

   *Login Enabled Tools*

Active 811 ticket
^^^^^^^^^^^^^^^^^^^

To get started, use **Search** to open an existing 811 Ticket using your ticket number. Once you open your ticket the Edit features and Manage documents tools are available. Information about the ticket is displayed:

* Ticket number
* Ticket Type
* Ticket URL

.. figure:: /_static/D-ActiveTicket1.png
   :alt: Active 811 Ticket
   :class: with-border

   *Active 811 Ticket*

Bookmarks
^^^^^^^^^^
You can add a **bookmark** to this ticket by clicking the **star** icon. This adds it to your **My Tickets** list where you can save tickets, features, and documents for easy access. 

There is also a link to download the GIS data in a GeoJSON file format. 

.. figure:: /_static/D-MyTickets1.png
   :alt: Bookmarked Ticket
   :class: with-border

   *Bookmarked Ticket*



.. caution::
   The FDC application is designed to **supplement** your 811 ticket. Not all utility information has been shared and some features in your ticket boundary may not be shown.
