About Field Data Collection
============================
Geospatial mapping technology for use at a dig site to review or create a map of underground utilities. Field Data Collection (FDC) works with the FuzionView software which aggregates all utility location data (GIS) into a single map “on the fly”.  Engineering design teams, facility operators, locators, excavators and homeowners will be able to use FDC on current or future construction sites. Emergency response teams can quickly gather critical information on site. 

Background
===========

During development of the FuzionView product, the need for a field based GIS data collection tool became apparent.
